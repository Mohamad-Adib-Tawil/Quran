# 03 — ميزات مقترحة للإضافة

مرتّبة حسب نسبة (الأثر ÷ الجهد). كل ميزة تنسجم مع البنية الحالية (Clean Architecture + Cubit + SharedPreferences).

---

## 🥇 الأولوية العالية (أثر كبير / جهد متوسط)

### 1. تكملة تلقائية للسور (Auto-play next) + قائمة تشغيل
- تشغيل السورة التالية تلقائياً (موجود جزئياً عبر `RepeatMode.next`) + شاشة "قائمة التشغيل" الحالية.
- يستفيد مباشرةً من ويدجت شاشة القفل (ملف 01) لأزرار التالي/السابق.

### 2. علامات مرجعية (Bookmarks) متعددة
- حالياً يوجد "آخر قراءة" واحدة فقط (`LastReadService`). أضف علامات متعددة بأسماء.
- تخزين: مفتاح JSON جديد `bookmarks_v1` في SharedPreferences.

### 3. أذكار/أدعية وختم القرآن (Khatmah Tracker)
- متتبّع خَتمة: هدف يومي بعدد الصفحات + شريط تقدّم نحو إتمام المصحف.
- يبني على `StudyToolsService` (Goals موجودة) — يحتاج فقط عرضاً مخصصاً.

### 4. وضع القراءة الليلي / السطوع المريح + الإبقاء على الشاشة مضاءة
- `WakelockPlus` لإبقاء الشاشة مضاءة أثناء القراءة.
- وضع "ورقي/داكن دافئ" لتقليل إجهاد العين.

### 5. تنبيه/تذكير ورد يومي (Local Notifications)
- `flutter_local_notifications` لتذكير المستخدم بوِرده اليومي في وقت يختاره.
- يربط بـ `StudyToolsService` (أهداف يومية).

---

## 🥈 الأولوية المتوسطة

### 6. تفسير الآيات (Tafsir)
- عرض تفسير مختصر (ابن كثير / السعدي) بالضغط على آية. يحتاج مصدر بيانات (asset JSON أو حزمة).

### 7. بحث داخل نص القرآن
- بحث عن كلمة/آية والانتقال إليها مباشرة. `quran` package يوفّر بيانات نصية.

### 8. مشاركة آية كصورة (Verse-to-Image)
- توليد صورة جميلة للآية ومشاركتها (`share_plus` موجود + `screenshot`/`RenderRepaintBoundary`).

### 9. تعدد القرّاء (Multiple reciters)
- حالياً CDN واحد ثابت. اجعل `AudioRemoteDataSource` يدعم اختيار القارئ (البنية مهيأة عبر `reciterId`).

### 10. مزامنة سحابية اختيارية (Backup/Restore)
- نسخ احتياطي للعلامات/الملاحظات/الأهداف (تصدير JSON أو Google Drive/iCloud). يكسر مبدأ "no backend" — اختياري.
