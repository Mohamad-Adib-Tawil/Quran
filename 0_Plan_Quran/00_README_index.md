## الوضع الحالي (خلاصة تقنية مهمة)

- **الصوت:** يعتمد على `just_audio` مباشرةً عبر `AudioPlayerDataSource`.
  - ❌ **لا يوجد** `audio_service` ولا `just_audio_background` → **لا توجد عناصر تحكم في شاشة القفل/الإشعارات**.
  - ⚠️ التشغيل في الخلفية قد يعمل جزئياً على iOS بسبب `AudioSessionConfiguration.music()`، لكنه **غير مضمون** على Android بدون Foreground Service.
- **الشبكة:** ❌ لا يوجد أي package لكشف الاتصال (`connectivity_plus` غير موجود)، ولا preflight قبل التشغيل/التحميل.
- **حالة الصوت:** `AudioCubit` + `AudioPhase` (8 حالات) — بنية نظيفة جاهزة للتوسعة.
